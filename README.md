# Kiran Academy Website

A responsive Kiran Academy-style education/training website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — website structure
- `style.css` — responsive design and animations
- `script.js` — mobile menu, scroll reveal and back-to-top button

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

## Customize
Replace the sample email, phone number, course information, statistics and testimonials in `index.html` with the official Kiran Academy details before publishing.
